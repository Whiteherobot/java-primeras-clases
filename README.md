# Tarea1 · Primeras clases en Java

Primera entrega de una tarea en grupo de Programación Orientada a Objetos
(Grupo 5, 1 de abril de 2022). Cada clase (`Gato`, `Perro`, `Animales`,
`estudiante` y `motos`) declara sus atributos y en su `main` crea un objeto para
imprimir uno de sus datos.

La versión terminada de esta tarea, con dos objetos por clase y todos sus datos,
está en [tare101](https://github.com/Whiteherobot/tare101). Este repo queda como
el primer avance.

## Ejecutar

```bash
mvn compile
java -cp target/classes Gato   # o Perro, motos, estudiante
```
